📖 Concept

What is Git & GitHub?

Two different things. People confuse them constantly. Let's fix that.

💻

Your Machine

Where you write code & work locally

→
🔧

Git

Tracks changes, saves snapshots locally

→
☁️

GitHub

Cloud storage for your code. Shareable & backed up

🔧 Git

Git is a free tool you install on your computer. It tracks every change you make to your code — think of it like "Ctrl+Z on steroids" with a full history of every save. It runs entirely on your machine with no internet required.

🐙 GitHub

GitHub is a website (owned by Microsoft) where you can upload your Git-tracked code to the cloud. It lets you share your projects, collaborate with others, and keep your work backed up so you never lose it. Think Google Drive, but built for developers.

⚙️ Setup

Installing Git on Windows

Three steps. Ten minutes. You'll never do this again.

1

Download Git for Windows

Get the official installer from git-scm.com. Use all the default options during setup — they're fine.

⬇ Download Git for Windows
2

Verify the installation

Open CMD or Git Bash and run this. You should see a version number.

bash 
git --version
# Expected output: git version 2.x.x.windows.x
3

First-time setup — tell Git who you are

You only do this once. Git stamps every commit with your name and email. Use your GitHub email.

bash 
git config --global user.name "Your Name"
git config --global user.email "you@email.com"

# Verify it worked:
git config --list
🐙 GitHub

Creating a GitHub Repository

A "repo" is just a folder for your project on GitHub. Here's how to make one.

1

Sign in to GitHub

Go to github.com and log in. If you don't have an account, create one — it's free.

[ Screenshot: GitHub homepage with Sign In button ]
2

Click "+" → "New repository"

Look for the + icon in the top-right corner of the page, next to your profile picture. Click it, then select New repository.

[ Screenshot: GitHub top navbar showing "+" dropdown menu ]
3

Name it, set to Public, click Create

Give your repo a clear name (no spaces — use hyphens like my-portfolio). Set it to Public, leave everything else as-is, and click Create repository.

🚀 Core Skill

Uploading Your Local Project

The real deal. Click each step to expand it — copy the command and run it in CMD.

Command Prompt — Your Project Upload Walkthrough
STEP 1 Switch to your project's drive E: ▶
C:\Users\You> E:
ℹ️ If your project is on C: drive, skip this. Replace E: with whatever drive letter your folder is on.
⚠ Common errors with this step ▼
"The system cannot find the drive specified"
→ The drive letter doesn't exist. Open File Explorer and check what drive your files are on.
STEP 2 Navigate to your project folder cd Portfolio\MyProject ▶
E:\> cd Portfolio\MyProject
ℹ️ Replace "Portfolio\MyProject" with the actual path to your folder. Use Tab to autocomplete.
⚠ Common errors with this step ▼
"The system cannot find the path"
→ Folder name is wrong. Use dir to list folders in the current directory and find the correct name.
STEP 3 Initialize Git in this folder git init ▶
E:\Portfolio\MyProject> git init
Initialized empty Git repository in E:/Portfolio/MyProject/.git/
ℹ️ This creates a hidden .git folder. Do NOT delete it — it's Git's brain.
STEP 4 Connect to your GitHub repo git remote add origin ... ▶
E:\Portfolio\MyProject> git remote add origin https://github.com/USERNAME/REPO.git
ℹ️ Replace USERNAME with your GitHub username and REPO with your repo name. Get this URL from GitHub → green "Code" button.
⚠ Common errors with this step ▼
"remote origin already exists"
→ Run git remote remove origin first, then add it again.
STEP 5 Stage all your files git add . ▶
E:\Portfolio\MyProject> git add .
ℹ️ The dot (.) means "everything in this folder." You can also stage one file: git add index.html
STEP 6 Commit — save a snapshot git commit -m "Initial commit" ▶
E:\Portfolio\MyProject> git commit -m "Initial commit"
ℹ️ The message in quotes is your commit note. Make it descriptive: "Add homepage layout" not "stuff".
⚠ Common errors with this step ▼
"nothing to commit, working tree clean"
→ Either you already committed, or git add didn't stage anything. Run git status to see what's happening.
"Please tell me who you are" error
→ You skipped Step 3 in the Install section. Run git config --global user.name and user.email.
STEP 7 Push to GitHub 🎉 git push -u origin master ▶
E:\Portfolio\MyProject> git push -u origin master
ℹ️ After this, future pushes only need: git push (no flags needed)
⚠ Common errors with this step ▼
"src refspec main does not match any"
→ Your branch is called "master" not "main". Use: git push -u origin master
HTTP 408 timeout / RPC failed
→ Run: git config --global http.postBuffer 524288000 then try again. Or use the web upload below.
"Everything up-to-date"
→ Actually good news — your files are already on GitHub. Check your repo in the browser.

🌐 Alternative: GitHub Web Upload (Drag & Drop)

If CMD is giving you grief, go to your repo on GitHub → click uploading an existing file → drag and drop your files → click Commit changes. It's slower but it works every time.

⚡ Reference

Everyday Git Commands

The 10 commands you'll use 90% of the time. Memorize these.

git status
See which files changed, what's staged, and what's not tracked yet.
git status
git add .
Stage ALL changed files — gets them ready to be committed.
git add .
git add filename
Stage just one specific file instead of everything.
git add index.html
git commit -m ""
Save a snapshot of your staged changes with a message.
git commit -m "Fix nav bug"
git push
Send your local commits up to GitHub. Do this after every commit.
git push
git pull
Download the latest changes from GitHub to your local machine.
git pull
git clone URL
Download an entire repo from GitHub to your local machine.
git clone https://github.com/user/repo.git
git log
See the full history of commits — who made what change and when.
git log --oneline
git branch
List all branches in your repo. The current one has an asterisk.
git branch
git checkout -b
Create a new branch and switch to it immediately.
git checkout -b feature-login

🛡️ System Health

System Repair: DISM & SFC

Windows acting weird? Corrupted files? Here's how to fix it like a pro.

⚠️
Run CMD as Administrator — right-click CMD → "Run as administrator". These commands won't work without elevated privileges.

DISM Higher Level

  • Repairs the Windows OS image itself
  • Connects to Windows Update to get clean files
  • Run this FIRST, before SFC
  • Takes 10–30 minutes (normal to stall at 20%)
  • Required if SFC fails or keeps failing

SFC File Level

  • Scans and repairs protected system files
  • Works from the repaired image DISM creates
  • Run this AFTER DISM completes
  • Usually takes 5–15 minutes
  • Fixes blue screens, missing DLLs, crashing apps

Step-by-Step Repair Order

1

DISM CheckHealth — Quick check

Fast scan to see if the image is flagged as corrupt. Doesn't fix anything.

cmd (Admin) 
DISM /Online /Cleanup-Image /CheckHealth
2

DISM ScanHealth — Deeper scan

More thorough. Scans the image for corruption but still doesn't repair. Takes a few minutes.

cmd (Admin) 
DISM /Online /Cleanup-Image /ScanHealth
3

DISM RestoreHealth — Actually fixes it

Downloads clean files from Windows Update and repairs corruption. This one takes 15–30 min. Don't panic if it stalls at 20% or 62% — that's normal.

cmd (Admin) 
DISM /Online /Cleanup-Image /RestoreHealth
4

SFC /scannow — Repair system files

Now that DISM has fixed the image, SFC can use it to repair individual corrupted system files. Restart your PC when it finishes.

cmd (Admin) 
sfc /scannow
📀 Offline Repair (when internet fails): Download a Windows ISO from microsoft.com, mount it (double-click the .iso), note its drive letter, then run:

DISM /Online /Cleanup-Image /RestoreHealth /Source:F:\Sources\install.wim /LimitAccess
Replace F: with your ISO drive letter.
🧠 Power User

Pro Tips

Small things that save you massive time. Use them daily.

⇥

Tab Completion

Start typing a folder name and press Tab to autocomplete it. Press Tab multiple times to cycle through matches. Saves half your typing.

↑↓

Command History

Press the ↑ and ↓ arrow keys to cycle through previously typed commands. Stop retyping the same thing.

🔐

Run as Administrator

For DISM, SFC, and any system-level commands: right-click CMD or PowerShell and select "Run as administrator". Without this, half the commands are blocked.

❓

Built-in Help System

Add /? to any command to see all options. Works for everything:
ipconfig /?   git --help

📋

Quick Copy in CMD

Right-click in CMD → Properties → enable QuickEdit Mode. Then you can select text with a click and drag, and right-click to paste. No more Ctrl+C nonsense.

🔄

Git .gitignore

Create a file named .gitignore in your project. List files/folders you never want to push (like node_modules/ or .env). Git will ignore them forever.

⚡

PowerShell > CMD

For advanced tasks, use PowerShell instead of CMD. It supports the same commands PLUS scripting, loops, and more power. Open it via Win+R → powershell.

🌿

Git Branches

Never work directly on master. Create a branch for each feature, test it, then merge. This keeps your main codebase clean and stable.

Quick Reference — Daily Git Workflow 
# Every time you make changes:
git status            # Check what changed
git add .             # Stage everything
git commit -m "msg"   # Save snapshot
git push              # Send to GitHub

# Or all in one line (alias this):
git add . && git commit -m "update" && git push
